# 会議プラットフォームと音声の取り込み

[English](MeetingPlatforms.md)

ルームを作るときに、会議の場所と音声の取り込み方法を選びます。どちらも後から **設定 → ルーム** で変更できます。参加者は全員、同じルームの URL を開いて共有キャンバスを見ます。音声は、以下のどれか 1 つの経路から入れば十分です。

| 場所            | 準備なし                                                   | 話者名をより正確に       | 本番向けの参加者別音声         |
| --------------- | ---------------------------------------------------------- | ------------------------ | ------------------------------ |
| 対面            | 部屋のマイク                                               | —                        | —                              |
| Google Meet     | ホストが Meet のタブを取り込む                             | 各自が自分のマイクを送る | 会議ボット (Recall.ai、実験的) |
| Zoom            | ホストが Zoom を取り込む (ウェブ版タブまたはシステム音声)  | 各自が自分のマイクを送る | Zoom RTMS または会議ボット     |
| Microsoft Teams | ホストが Teams を取り込む (ウェブ版タブまたはシステム音声) | 各自が自分のマイクを送る | 会議ボット                     |

音声が端末から出る前に同意ダイアログが出ます。会議の参加者全員が、文字起こしされることを知り、同意している必要があります。

## 対面: 部屋のマイク 1 本

1. マイクの良いノート PC をテーブルの中央に置きます。ブラウザは Chrome か Edge を使います。
2. **対面** と **部屋のマイク** でルームを作ります。
3. **音声 → 取り込み開始** を押します。

小さな声や遠い声を消さないよう、ブラウザのエコー除去・ノイズ抑制・自動ゲインはオフにしています。話者は Soniox が区別します (「Speaker 1」「Speaker 2」と表示されます)。文字起こしの名前をクリックすると変更できます。

## Google Meet

### ホストが Meet のタブを取り込む (準備不要)

1. Google Meet を Chrome か Edge の**通常のタブ**で開きます (インストールしたアプリのウィンドウは不可)。
2. **Google Meet** と **ホストが会議音声を取り込む** でルームを作ります。
3. **音声 → 取り込み開始** を押し、選択画面で **Meet のタブ**を選んで「**タブの音声も共有する**」にチェックします。

Meet のタブには、**ほかの参加者**の声だけが入っており、これは話者分離されます。ホスト自身のマイクは、ホストの名前を付けた別のストリームとして送られます。ホストがスピーカーで聞いていると、ほかの参加者の声がホストのマイクにも回り込みます。サーバーの `EchoGuard` がこの重複を取り除きますが、ヘッドホンを使うのが最善です。

### 各自が自分のマイクを送る

各参加者がルームを開いて名前を入力し、**音声**を開始します。文字起こしには本人の名前が付きます。全員ヘッドホンを使ってください。

### Google Meet アドオン (Meet の中にキャンバスを表示)

アドオンを使うと、Meet の中で EkklesiazousAI を使えます。

- **サイドパネル (個人用):** こっそり解説、文字起こし、コマンドバー。
- **メインステージ (共有):** 通話の全員にキャンバスを表示します。参加者はそれぞれ自分のフレームで操作します。

1. Google Cloud プロジェクトを作り、**プロジェクト番号**を控えます。
2. **Google Workspace Marketplace SDK** と **Google Workspace add-ons API** を有効にします。
3. EkklesiazousAI を **HTTPS** で配信します (`pnpm build && pnpm start` を TLS プロキシやトンネルの裏で動かす)。
4. 次のようなマニフェストで HTTP デプロイメントを作ります (フィールド名は Google の最新ドキュメントで確認してください)。

   ```json
   {
     "addOns": {
       "common": { "name": "EkklesiazousAI", "logoUrl": "https://YOUR_HOST/Favicon.svg" },
       "meet": {
         "web": {
           "sidePanelUrl": "https://YOUR_HOST/addon/meet/sidepanel",
           "addOnOrigins": ["https://YOUR_HOST"]
         }
       }
     }
   }
   ```

5. `.env` に `VITE_MEET_CLOUD_PROJECT_NUMBER` を設定し、クライアントをビルドし直します。
6. デプロイメントをインストールし、Meet の通話で **アクティビティ** を開きます。サイドパネルでルームを作り、**キャンバスを全員に表示** を押します。

アドオンからは会議の音声を取れません。上のいずれかの取り込み方法と組み合わせてください。Google のリアルタイム **Meet Media API** は新規登録を受け付けていない (2026 年 10 月時点) ため、対応していません。

### 会議ボット (実験的)

`RECALL_API_KEY` を設定し、`PUBLIC_BASE_URL` を HTTPS で外部から到達できるようにします (ngrok など)。**会議ボット** でルームを作り、**音声 → ボットを招待** に Meet のリンクを貼り付けます。ホストがボットの入室を承認する必要があります。参加者ごとの声が名前付きで別々に届きます。費用はボット約 $0.50/時と、話している人数分の音声認識です。

## Zoom

### ホストが Zoom を取り込む

- **Zoom ウェブ版:** Zoom のタブを選び「**タブの音声も共有**」にチェックします。
- **Windows の Zoom デスクトップ版:** 「**画面全体**」を選び「**システム音声を共有**」にチェックします。
- **macOS の Zoom デスクトップ版:** システム音声の取り込みには新しい Chrome と macOS が必要です。確実なのは Zoom ウェブ版です。

Google Meet と同様、ホストのマイクは名前付きの別ストリームで送られます。

### Zoom RTMS (Zoom のサーバーから参加者別の音声)

必要なもの: Zoom の Pro / Business / Enterprise アカウントと Zoom Developer Pack のクレジット、および「アプリによる会議コンテンツへのアクセス」を許可したアカウント管理者。

1. Zoom App Marketplace で **General (OAuth)** アプリを作り、スコープ `meeting:read:meeting_audio` を付けます。
2. イベントサブスクリプション `meeting.rtms_started` と `meeting.rtms_stopped` を追加し、エンドポイント URL を `https://YOUR_HOST/api/zoom/webhook` にします。Zoom の URL 検証にはサーバーが自動で応答します。
3. `.env` に `ZOOM_CLIENT_ID`、`ZOOM_CLIENT_SECRET`、`ZOOM_WEBHOOK_SECRET_TOKEN`、`PUBLIC_BASE_URL` を設定します。
4. **Zoom** と **Zoom RTMS** でルームを作り、**設定 → ルーム** に Zoom の会議 ID を入力します。ルームが稼働しているよう、ブラウザで開いておいてください。
5. 会議で RTMS アプリを開始します (自動開始、またはホストが開始)。参加者ごとの音声が Zoom の表示名付きで届きます。

公式 SDK が Windows で動かないため、サーバーは RTMS の WebSocket プロトコルを直接実装しています。ブレイクアウトルームは取り込めません。

### 会議ボット

Google Meet と同じです。Zoom の参加リンクを貼り付けます。

## Microsoft Teams

- **ホストが取り込む:** Teams ウェブ版なら Teams のタブを選び「**タブの音声も共有**」にチェックします。Windows の Teams デスクトップ版なら「**画面全体**」を選び「**システム音声を共有**」にチェックします。
- **各自が自分のマイクを送る。**
- **会議ボット:** Teams の参加リンクを貼り付けます。

## デモ

ロビーの **デモ会議を開始** を押すと、マイクなしで日英混在のスクリプト会議が再生されます。API キーを設定していれば、デモ会議を本物の AI と検索サービスで処理するので、動作確認に便利です。
